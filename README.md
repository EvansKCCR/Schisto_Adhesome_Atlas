# Exploratory Schisto-adhesome atlas 

## Overview

This repository supports the generation of an interactive adhesome atlas that employs deterministic multi-evidence integration, graph-theoretical network reconstruction, mechanistic simulation and exploratory multi-criteria prioritization of schistosome adhesion protein candidates.

## Repository Contents

- Data retrieval and preprocessing workflows
- Protein domain annotation pipelines
- Conserved motif analysis workflows
- Orthology inference and comparative genomics analyses
- Phylogenetic reconstruction workflows
- Network construction and module detection analyses
- Target prioritisation frameworks
- Supplementary thesis datasets
- Source code supporting the interactive atlas

## Data Sources

Primary datasets were obtained from:

- WormBase ParaSite: https://parasite.wormbase.org/
- NCBI RefSeq and Gene Resources: https://www.ncbi.nlm.nih.gov/datasets/taxonomy/9606/

## Reproducibility

All custom scripts used for data acquisition, processing, annotation, orthology analysis, phylogenetic reconstruction, network analysis, prioritisation, and atlas generation are maintained under version control.

Repository: https://github.com/EvansKCCR/Thesis

## Supplementary Datasets

The accompanying datasets include:
