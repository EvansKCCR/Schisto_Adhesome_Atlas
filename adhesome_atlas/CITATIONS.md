# Resource citations

These references acknowledge the databases and methods relevant to the atlas. Publication years do not specify the release used in an individual analysis. Preserve release numbers, accession IDs, query settings and run dates from the original outputs when reporting results.

## STRING

[STRING 12.5 resource link supplied for this atlas](https://version-12-5.string-db.org/).

Szklarczyk D et al. (2025). **The STRING database in 2025: protein networks with directionality of regulation.** *Nucleic Acids Research*. [Publication](https://pubmed.ncbi.nlm.nih.gov/39558183/).

Used to contextualize the supplied protein-association networks and evidence channels. The resource URL is retained as requested; the exported TSV files do not independently establish their STRING release. STRING associations are not automatically direct physical interactions.

## ELM

[Eukaryotic Linear Motif resource](http://elm.eu.org/).

Kumar M et al. (2024). **ELM—the Eukaryotic Linear Motif resource—2024 update.** *Nucleic Acids Research*, 52(D1), D442–D455. [doi:10.1093/nar/gkad1058](https://doi.org/10.1093/nar/gkad1058).

Reference for ELM classes and motif interpretation. Sequence-pattern matches in this atlas remain candidate motifs, not validated binding sites.

## UniProt

[UniProt](https://www.uniprot.org/).

The UniProt Consortium (2025). **UniProt: the Universal Protein Knowledgebase in 2025.** *Nucleic Acids Research*, 53(D1), D609–D617. [doi:10.1093/nar/gkae1010](https://doi.org/10.1093/nar/gkae1010). [Official citation guidance](https://www.uniprot.org/help/publications).

Protein sequence, accession and functional-reference resource.

## InterPro

[InterPro](https://www.ebi.ac.uk/interpro/).

Blum M et al. (2025; published online 2024). **InterPro: the protein sequence classification resource in 2025.** *Nucleic Acids Research*. [doi:10.1093/nar/gkae1082](https://doi.org/10.1093/nar/gkae1082). [Official citation guidance](https://interpro-documentation.readthedocs.io/en/latest/citing.html).

Reference for integrated protein-family and domain classification. An InterPro citation does not imply that a new InterProScan analysis was run by the atlas.

## NCBI CDD and Batch CD-Search

[NCBI Conserved Domain Database](https://www.ncbi.nlm.nih.gov/Structure/cdd/cdd.shtml).

Wang J et al. (2023). **The conserved domain database in 2023.** *Nucleic Acids Research*, 51(D1), D384–D388. [doi:10.1093/nar/gkac1096](https://doi.org/10.1093/nar/gkac1096).

The supplied hit files identify Batch CD-Search. Its recommended additional references are:

- Marchler-Bauer A, Bryant SH (2004). **CD-Search: protein domain annotations on the fly.** *Nucleic Acids Research*, 32(Web Server issue), W327–W331. [Publication](https://pubmed.ncbi.nlm.nih.gov/15215404/).
- Marchler-Bauer A et al. (2011). **CDD: a Conserved Domain Database for the functional annotation of proteins.** *Nucleic Acids Research*, 39(Database issue), D225–D229. [doi:10.1093/nar/gkq1189](https://doi.org/10.1093/nar/gkq1189).

[NCBI citation instructions](https://www.ncbi.nlm.nih.gov/Structure/cdd/docs/cdd_publications.html).

## SignalP 6.0

[SignalP 6.0 server and citation](https://services.healthtech.dtu.dk/services/SignalP-6.0/).

Teufel F et al. (2022). **SignalP 6.0 predicts all five types of signal peptides using protein language models.** *Nature Biotechnology*. [doi:10.1038/s41587-021-01156-3](https://doi.org/10.1038/s41587-021-01156-3).

Method reference for supplied signal-peptide and cleavage-site predictions.

## DeepLoc 2.1

[DeepLoc 2.1 server and citation](https://services.healthtech.dtu.dk/services/DeepLoc-2.1/).

Ødum MT et al. (2024). **DeepLoc 2.1: multi-label membrane protein type prediction using protein language models.** *Nucleic Acids Research*, 52(W1), W215–W220. [doi:10.1093/nar/gkae237](https://doi.org/10.1093/nar/gkae237).

Method reference for supplied subcellular-localization and membrane-type predictions.

## DeepTMHMM

[DeepTMHMM server and citation](https://services.healthtech.dtu.dk/services/DeepTMHMM-1.0/).

Hallgren J et al. (2022). **DeepTMHMM predicts alpha and beta transmembrane proteins using deep neural networks.** *bioRxiv*, preprint. [doi:10.1101/2022.04.08.487609](https://doi.org/10.1101/2022.04.08.487609).

Method reference for supplied transmembrane-topology predictions. The official tool name is DeepTMHMM (the requested “DeepTMHH” refers to this tool). The reference above is the preprint recommended by the tool's server.

## WormBase ParaSite

[WormBase ParaSite](https://parasite.wormbase.org/).

Howe KL, Bolt BJ, Shafie M, Kersey P, Berriman M (2017). **WormBase ParaSite—a comprehensive resource for helminth genomics.** *Molecular and Biochemical Parasitology*, 215, 2–10. [doi:10.1016/j.molbiopara.2016.11.005](https://doi.org/10.1016/j.molbiopara.2016.11.005). [Official citation guidance](https://parasite.wormbase.org/info/about/publications.html).

Helminth genome and gene-model reference resource. Report the actual WBPS release and assembly accession used for each proteome separately.
