Biological context & visual legend

Node radius: 12 + 4 × log₂(1 + unique candidates). Confidence outline: solid = A/B only; dashed = C only; dotted = mixed supported + provisional. These are family annotation grades, independent of edge evidence. Labels that would collide are suppressed; hover or select for the full identifier.

Edges: existing undirected metazoan reference-family projections onto orthogroups. Multiple evidence rows share one path and remain inspectable by clicking a highlighted edge. Reference findings are not new schistosome interaction validation; no downstream direction is inferred.
